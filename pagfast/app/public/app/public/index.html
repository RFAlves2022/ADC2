PagFast: infraestrutura segura para transações rápidas e estáveis.

A PagFast é uma plataforma fictícia criada para demonstrar uma arquitetura Linux com foco em segurança, organização de arquivos, automação de serviços e publicação web.

O que a PagFast entrega

Uma vitrine simples para simular um sistema de pagamentos com boa base de infraestrutura.

Pagamentos rápidos

Estrutura pensada para representar disponibilidade e resposta ágil em um serviço crítico.

Segurança operacional

Pastas protegidas, usuários restritos e separação entre administração e acesso comum.

Automação

Um script Bash monitora o serviço e ajuda a manter a aplicação disponível.

Segurança e controle de acesso

A PagFast foi criada para demonstrar o uso de grupos, permissões e usuários restritos no Linux. A área de auditoria é protegida para representar informações internas da empresa.

  • Usuário administrativo com acesso controlado.
  • Usuário restrito sem permissão nas pastas críticas.
  • Separação clara entre público, logs e auditoria.
Ambiente da infraestrutura
app/public
Arquivos públicos da aplicação
app/logs
Registros e logs do sistema
auditoria
Pasta protegida para evidenciar permissões e acesso negado

Infraestrutura sob medida

A parte principal do projeto é provar que o sistema operacional organiza, protege e mantém o serviço em funcionamento.

1. Organização

Estrutura de diretórios criada por terminal para simular um ambiente real de produção.

2. Permissões

Controle de acesso com dono, grupo e outros usuários, refletindo a política de segurança da empresa.

3. Disponibilidade

Script de monitoramento e container web para manter a aplicação acessível com simplicidade.
